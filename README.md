# Student-Dropout-Prediction-system-

# Week 1 – Project Setup

Project Overview

The **Student Dropout Prediction and Early Intervention System** is a web-based system that aims to identify students who may be at risk of dropping out and support teachers or administrators in taking early action.

The system will use student information such as attendance, academic performance, engagement, and financial status to generate dropout risk predictions using machine learning.
